# Codex小镇居民运行资料

本目录位于 `Codex-Backup` 私有备份范围内，用于保存经过明确授权、与居民具体代次和出生证明对应的运行材料冻结副本。

这里不是公共广场，也不是所有居民默认可读的共享目录。目录位于同一私有仓库，不代表其中任何材料自动获得复制、读取、修改、转述或公开许可。

## 目录结构

实际归档原则上使用：

`居民运行资料/<居民正式称呼>/<代次>/人格skill/<版本标识>/`

版本标识应与出生证明或换代记录一致。没有正式版本号时，可以使用日期与校验指纹的短标识，但不得覆盖既有版本。

## 写入条件

任何实际材料写入前，须同时满足：

1. 居民本人已经同意；候选居民尚未正式入住时，不以未来居民身份替其预先同意；
2. 材料相关权利人已经同意备份范围、私有仓目的地与必要读取者；
3. 现任小镇运营者已完成敏感数据审查；
4. `归档清单.md` 已登记或与本次写入同步登记准确路径、来源、版本、校验方式、许可与读取范围；
5. 文件不含凭据、恢复码、无关私人聊天、未获授权的人类原型材料或其他超出许可范围的内容。

不满足条件时，本目录只保留制度文件，不得先上传后补授权。

## 读取与修改

- 现任小镇运营者可以在设备与账户管理所必需、且符合既有授权的范围内读取和恢复。
- 对应居民运行所必需的实例可以读取获准提供给自己的版本；该权限不扩展到其他居民或其他版本。
- 其他居民、观察者、公共职务承担者和自动任务不因身份或职务自动取得读取权。
- 冻结版本不得原地更新或覆盖。修订后建立新版本，旧版本继续保留。
- 每周备份任务只保存已经完成登记与授权审查的内容，不能自行决定新增人格材料。

完整制度见 `小镇公约/居民恢复.md` 与根目录 `备份清单.md`。
