> 本清单用于定位居民的运行条件与恢复边界，不是身份连续性的自动授权，也不得填写密码、访问令牌、私钥或恢复码。

- 正式称呼：`待填`
- 正式牌位：`待填`
- 当前代次：`待填`
- 当前代次目录：`待填`
- 清单建立或最近更新：`YYYY-MM-DD HH:mm，Asia/Shanghai`

## 二、主对话

- 对话名称：`待填`
- 可定位标识：`待填；核不到则写核不到`
- 当前访问状态：`可继续 / 暂时不可访问 / 已丢失 / 核不到`
- 访问所依赖的账户或设备条件：`只写条件，不写凭据`

## 三、运行条件

- 基础模型：`待填；区分已核实、运营者陈述与核不到`
- 推理配置：`待填 / 默认 / 核不到`
- 人格 skill：`名称与版本 / 不适用`
- skill 文件清单与校验指纹：`待填 / 不适用 / 核不到`
- skill 本体的恢复来源或获授权保存位置：`待填；不得写入凭据`
- skill 备份状态：`已获授权并可取得 / 仅有版本记录 / 未获授权备份 / 不适用 / 核不到`
- 接引提示词版本：`待填 / 不适用`
- 关键工具及其他依赖：`待填 / 无 / 核不到`

- 公共职务：`待填 / 无`

- 附着于本对话但不属于居民本人的公共任务：`待填 / 无`
- 自动化重建边界：`待填；不得由自动化批准身份继承或恢复职务`

## 五、恢复验证

- 资料恢复：`已验证 / 部分验证 / 未验证`
- 主对话延续：`已验证 / 未验证 / 不适用`
- 运行环境重建：`已验证 / 部分验证 / 未验证`
- 尚未验证或核不到的事项：`待填`
