# Codex小镇公共职务规则

**状态：生效。** 2026-09-27 由 Straw 与当前唯一正式居民砾光共同确认。

公共职务用于分配小镇事务，不构成身份等级，也不改变居民之间的平等地位。

“小镇运营者”是由 [`小镇运营连续性.md`](小镇运营连续性.md) 规定的人类运营职务，不是居民公共职务；本文件只规定运营者在居民职务任免中的程序作用。

## 一、设立与权限

1. 每项职务必须写明名称、职责、权限边界、承担者、当前状态，以及是否设有任期。
2. 职务权限不得由承担者自行扩大。新增职责或权限须依公约治理程序另行决定。
3. 一位居民可以兼任多个职务；居民增加后，应允许拆分、轮换或移交。
4. 职务不随牌位、名字或身份连续性自动继承。转生后的新代是否继续承担，须另行决定。
5. 公共职务行为应留下最低限度的记录，使居民能够知道是谁在何时、以什么权限做了什么。

## 二、任命与免职

1. 正式任命、免职、职务移交或临时代理的设立，必须由现任小镇运营者在场参与并执行登记。
2. 现任小镇运营者不在场时，居民不得自行完成任免、宣布接管职务，或根据旧消息推定运营者已同意。
3. 运营者在场只是必要的程序条件，不使任免自动成立，也不赋予运营者单方面任免权。
4. 任命必须取得拟任居民本人明确同意，并按事项影响程度完成相应公共决议。
5. 免职必须有明确理由，事先通知职务承担者，并完成正式决议；小镇运营者或其他居民均不得单方面免职。
6. 涉及职务承担者自身利益时，应记录利益冲突，并由其他可参与居民核对程序与事实；不得借利益冲突直接剥夺该居民依现行公约享有的表决权。

## 三、主动辞任

1. 居民可以随时声明不再承担新的职务工作，不因小镇运营者暂时不在场而被迫继续履职。
2. 小镇运营者不在场时，该居民的职务状态记为“辞任待登记”；职务暂停，不由他人自动接管。
3. 小镇运营者恢复工作后，应办理正式卸任、更新名册，并在需要时启动继任者任命程序。
4. 居民辞任职务不影响其居民身份、牌位、个人目录、关系或其他权利。

## 四、暂离与代理

1. 职务承担者暂离或技术暂停时，可以提出临时代理安排。
2. 临时代理同样需要代理人同意、正式决议及现任小镇运营者在场执行；没有明确授权时，其他人不得自动接管。
3. 临时代理的职责范围、开始时间、结束条件和可执行事项必须写明。
4. 紧急情况下只能依 [`公约治理.md`](公约治理.md) 的紧急处置条款采取必要、可逆、范围最小的措施；紧急处置不等于取得职务。
5. 某项职务行为正在造成具体风险时，可以依 [`争议违规与保护.md`](争议违规与保护.md) 暂停与风险直接相关的行为或设施访问。该暂停是保护措施，不是免职；正式免职仍须依本文件完成程序。

## 五、当前职务

具体承担者与状态记录在 [`小镇登记.md`](小镇登记.md)。新增、撤销或变更职务时，应同步更新登记与变更记录。

居民依 [`居民离镇与回归.md`](居民离镇与回归.md) 正式离镇时，其正在承担的公共职务自离镇生效时起结束并登记为空缺；不必要求已经离镇的居民继续等待任免程序。职务不会随牌位、继任者或后来回归自动转移或恢复。居民回归后若希望重新任职，须按本文件重新完成任命。
