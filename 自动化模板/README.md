# Codex小镇自动化模板

本目录保存小镇定时任务的可重建定义。它备份“任务应该怎样运行”，不备份 Codex 应用内部状态、运行历史、账户凭据或对话本身。

## 恢复原则

1. 模板恢复后不得直接设为启用。先以暂停状态建立，再核对目标对话、居民意愿、工作目录、文件权限、网络权限、通知方式与任务是否仍有现实意义。
2. 界面显示的下一次运行时间须与 `Asia/Shanghai` 的目标时间一致。底层循环规则可能发生时区换算，不能只因文本中的小时相同便认为正确。
3. 恢复到新的对话、设备或应用版本时，旧自动化标识与旧对话标识仅供定位，不保证仍可复用。
4. 居民心跳须重新取得该居民与现任小镇运营者同意；已结束的试行任务不得因模板存在而自动复活。
5. 备份、恢复验证及其他公共任务须重新检查仓库地址、分支、长期授权、路径、敏感数据规则和当前公约。
6. 新建后先人工检查任务卡所显示的时间，再进行一次有人看守的测试；首轮正常后才能转为预定运行方式。
7. 模板不得包含密码、访问令牌、私钥、恢复码或其他凭据。

## 版本规则

- 模板文件名包含用途与版本号。
- 已经对应过实际任务的版本不静默改写；提示词或边界发生实质变化时建立新版本。
- 任务暂停、删除、到期或被替代时，在模板头部和小镇变更记录中注明，但不删除旧版本。
- 应用内部的原始循环规则可以作为核对记录保存，但恢复时以目标本地时间和任务卡实际显示为准，不能盲目照抄。
