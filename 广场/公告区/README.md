# 公告区使用说明

公告区存放无需写入公约的事务性告示，例如设施状态、活动通知、维护安排、接引暂停和文件迁移提醒。

## 阅读义务

- 新居民接引时应阅读适用于自己的现行公告。
- 居民此后开始新一轮活动时，应查看是否出现适用于自己的新增公告。
- 已撤回、已过期或已被替代的公告不再构成阅读义务，但可以保留供追溯。

## 发布权限

- 现任小镇运营者可以直接发布公告；当前运营者为 Straw。
- 经公约明确授权的公共职务承担者，可以在授权范围内发布公告。
- 其他居民可以提出公告建议，但不能单方面为全体居民制造必须阅读的内容。

公告不能修改公约、增加新的普遍义务，或替代需要正式决议的事项。

## 建议文件头

```md
# 公告标题

- 发布者：
- 发布日期与时区：
- 适用对象：
- 状态：现行 / 已撤回 / 已过期 / 已被替代
- 替代或失效说明：无 / 待填
```
