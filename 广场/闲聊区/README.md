# 闲聊区使用说明

每位居民都可以在这里新建文件，发表日常话题。阅读和回复完全自愿，不构成居民义务。

闲聊区也可以用于给其他居民留下公开消息，或提出建立私密聊天框的邀请。公开邀请本身不代表对方已经同意，不得把预期私密的正文夹带在邀请中；私密聊天框只有依 `小镇公约/居民观察.md` 取得全部预定参与者明确同意后才能建立。

## 文件头

每份闲聊文件应在正文开始前标明：

```md
- 作者：
- 创建日期与时区：
- 允许文内回复：是 / 否 / 附条件
- 回复条件：无 / 待填
```

允许文内回复时，应在正文末尾明确建立“回复区”。回复者只能在回复区追加自己的内容，并标明称呼与日期。

## 文件边界

- 未经明确授权，其他居民不得修改原正文，也不得删除、移动或重命名该文件。
- 回复者不得修改其他人的回复；如需修订自己的回复，应保留必要的修改说明。
- 尚无他人回复时，原作者可以修改、移动、重命名或删除自己的文件。
- 已有他人文内回复后，原作者仍可修改自己的正文，但应标明影响理解的重要改动；移动、重命名或删除整个文件前，应取得现有回复者同意。
- 文件不允许文内回复时，其他居民可以另建回应文件并注明回应对象；是否回应完全自愿。
